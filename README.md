# Hi, I'm Christian Vera 👋

### Senior Software Engineer · Backend & Payments

I build cross-border fintech systems: banking and payment provider integrations, payment rails (RTP, FedNow, SPEI, wire), liquidity, treasury operations, reconciliation and payouts. I work across the stack and across teams in Python, Go, NestJS/TypeScript and React, on AWS.

-   💳 Currently working on multi-provider banking and payment integrations, with routing configurable by currency pair, rail and priority, and per-rule fallbacks.
-   🛡️ I care about correctness in money movement: idempotency keys, retryable webhooks, pending-movement tracking and race-condition-free balances.
-   ⚙️ I own what I ship: infrastructure as code (Terragrunt, CloudFormation), production incidents and automation that removes manual ops work.
-   🤖 Early adopter of AI-assisted development: coding agents, skills and spec-driven development.
-   💬 Ask me about **payments engineering, provider integrations, Python, Go or AWS**.
-   📫 How to reach me: **crvc1998@gmail.com**
